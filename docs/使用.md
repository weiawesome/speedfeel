# 使用

打開頁面後會自動量一次下載速度，只量這一次。按鈕寫著「測量中」時就是在量。量完，滑桿會停在測到的 Mbps。

測到的是開這個網站時的下載速度。別的網站不一定一樣，對方的伺服器也會影響。想再量一次，按「測速」。

## 選一個網速

滑桿是「如果方案是這個 Mbps，會是什麼感覺」。可以拉得比剛測到的速度更快，也可以更慢。上面的 3G、4G、5G 是速度帶，不是一個固定的 Mbps：

| 帶 | 範圍 | 點下去會跳到 |
| --- | --- | --- |
| 3G | 低於 6Mbps | 2Mbps |
| 4G | 6Mbps 以上、低於 60Mbps | 20Mbps |
| 5G | 60Mbps 以上 | 150Mbps |

下面還有幾個固定速度：512K、1M、5M、10M、21M、100M。拖曳滑桿時數字跟著手指走。

## 三個畫面

底下或上方可以切「影片」、「短影音」、「動態」。

- **影片**：長片。畫質在播放器裡面選，從 240p 到 2160p，也可以交給自動。進度條可以拖，拖曳時畫面跟著走，放開後會重新緩衝。
- **短影音**：上下滑。畫質在播放器外面，最高 1080p。
- **動態**：字先到，圖和影片依序出現。沒有另外的畫質選單。

每個畫面外面有一個循環圖示。影片和短影音會換成另一種播放器，動態會換成另一種版面。

說明文字會寫這個畫質每秒要多少、管子現在是多少、播不播得動。按「重來」會把目前這段模擬從頭再跑一次，不會重新測速。
